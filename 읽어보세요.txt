도안 나눔 페이지 사용법
=====================================

[1] 그림 넣기
    도안이미지/ 폴더에 그림 파일을 넣으세요. (png, jpg, heic 다 됩니다)

    · 파일 이름이 그대로 페이지 제목이 됩니다.
    · 순서를 정하고 싶으면 앞에 번호를 붙이세요.
        01-스테고사우루스.png
        02-브라키오사우루스.png
      → 화면에는 "스테고사우루스", "브라키오사우루스" 로 나옵니다.
    · A4 세로 비율(1:1.414)에 맞춰 보이니, 세로로 긴 그림이 제일 예쁘게 들어갑니다.


[1-2] 그림 다듬기  (새로 넣은 그림이 있을 때)
    터미널에서  python3 도안다듬기.py  를 실행하세요.

    · 그림 둘레의 테두리 네모를 지웁니다.
    · 기울어진 사진을 수평으로 세웁니다.
    · 남는 흰 여백을 잘라냅니다.
    · 바탕을 완전한 흰색으로 맞춥니다.

    원본은 도안원본/ 에 그대로 복사해둡니다. 다시 실행해도 늘 원본에서
    새로 다듬으므로 여러 번 돌려도 그림이 상하지 않습니다.

    그림별로 손볼 게 있으면 도안다듬기.py 위쪽 표를 고치세요.
        GLYPH_ERASE  그림 안에 적힌 손글씨 지우기
        ROTATE       비뚤게 그려진 그림 돌리기 (양수=반시계, 음수=시계)
        TOUCHUP      뾰족한 선을 둥근 곡선으로 바꾸기


[2] 페이지 만들기
    페이지만들기.command  를 더블클릭하세요.
    (검은 창이 뜨고 몇 초 뒤 브라우저에서 페이지가 열립니다)

    ※ 처음 한 번은 "확인되지 않은 개발자" 경고가 뜰 수 있어요.
      그 파일에서 마우스 오른쪽 클릭 → 열기 → 열기 를 누르면 됩니다.
    ※ 그림을 추가하거나 바꿀 때마다 다시 눌러주세요.


[3] 공유하기
    · 그림만 보내면 될 때 →  공유페이지.html 파일 하나만 보내세요.
      (그림이 파일 안에 들어있어서 그림·다운로드 버튼이 다 살아있습니다.
       단, 영상은 안 보입니다)

    · 영상까지 같이 보여주고 싶을 때 →  drawing 폴더를 통째로 압축해서 보내거나,
      웹에 올리세요. (인스타 링크에 걸려면 웹에 올리는 쪽이 편합니다)


[4] 페이지에 있는 버튼
    도안 전체 받기 →  모든 도안을 도안모음.zip 한 파일로 저장
    각 도안의 '받기' →  그 그림 한 장만 저장
    A4로 인쇄하기 →  도안이 한 장에 하나씩 A4로 인쇄됩니다 (영상 칸은 인쇄 안 됨)


-------------------------------------------------------------------------------
폴더 설명

  도안이미지/        ← 여기에 그림을 넣으세요 (이 폴더만 만지면 됩니다)
  도안원본/          다듬기 전 원본 보관. 지우지 마세요.
  영상/              H.264로 변환한 영상. 페이지가 이걸 재생합니다.
  포스터/            영상 썸네일. 파일명은 영상/ 과 똑같이 맞춰주세요.
  *.MP4              아이폰에서 나온 원본 영상 (HEVC). 보관용.
  공유페이지.html     결과물
  만들기.py          페이지를 만드는 코드
  도안다듬기.py      그림을 다듬는 코드
  도안/              (안 씁니다. 지우셔도 됩니다)


도안 아래 영어 단어 바꾸기
  만들기.py 의 ENGLISH 에 한 줄 추가하세요.
      "한글제목": "English",
  여기에 없는 도안은 한글 제목만 나옵니다.


섹션(공룡 · 바다동물 · …) 바꾸기
  만들기.py 의 SECTIONS 를 고치세요. 적은 순서대로 화면에 나옵니다.
  목록에 없는 도안은 맨 아래 '그 밖에' 로 모입니다.


도안 맨 아래 저작권 한 줄 바꾸기
      SHEET_CREDIT = "ⓒ luckyyy.mommy"


제목·소개글 바꾸기
  만들기.py 파일을 열어서 위쪽의 이 부분을 고치면 됩니다.
      PAGE_TITLE = "엄마표 그림 도안 나눔"
      PAGE_SUB   = "..."
      CREDIT     = "@luckyyy.mommy"

영상 제목 바꾸기 / 영상 추가하기
  만들기.py 의 VIDEO_LABEL 에 한 줄 추가하세요.
      "파일이름(확장자 빼고)": "화면에 보일 제목",
  영상/ 폴더에 mp4 를 넣고, 같은 이름의 jpg 를 포스터/ 에 넣으면 썸네일도 나옵니다.
